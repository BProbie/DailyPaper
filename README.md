## ⭐诞生背景

我刚重置完电脑看着电脑桌面上展示的操作系统自带的经典壁纸陷入了沉思：我该选一张怎样的壁纸呢？

这一张壁纸我好像已经用了很久以至于早就看腻了因此我再一次陷入了沉思：我又该换一幅怎么样的新壁纸呢？

在浏览器的图片搜索区域输入壁纸相关的关键词寻觅了一段时间却仍然没有找到令我满意的壁纸后，我再再一次陷入了沉思：这些壁纸要么不是我想要的，要么就是有水印，要么就是不够高清，找个适合的壁纸怎么就这么难呢？

终于在给我的电脑桌面换上了一张好看的壁纸后，我静静地坐在电脑前静静地欣赏电脑桌面上那一张静静的壁纸，我再再再一次陷入了沉思：如果我能够让我的壁纸动起来，或者说能够将一张动图设为动态壁纸就好了，但是，可以吗？

今天是新年，生活中周围都洋溢着新春喜庆的大红，看着电脑上不和氛围的壁纸，但是在浏览器上又找不到可以令我满意的壁纸，既懒得花大量时间找合适的壁纸，又宅在家里死敲代码的我再再再再一次陷入了沉思：我可不可以让符合此时此刻我心情的壁纸一张一张轮流地自己跑到我的电脑桌面上呢？

这一次，我再再再再再一次陷入了沉思，于是，DailyPaper（Daily+AI+Wallpaper），诞生了！



## ⭐核心场景

AI长聊天根据个性偏好不断生成或修改高清壁纸。

上传多张图片素材利用AI不断生成或修改同类型的高清壁纸。

上传GIF等格式的动态图片将其设置为动态壁纸并调节其轮播速度。

根据你的喜好心情结合当天的时间地点、日期星期、节气节日、风俗风气、历史文化每隔特定时间自动推送相关具有浓郁气氛氛围的每日壁纸。

## ⭐使用教程

### Chat聊天（AI智能聊天）

你可以在这里与本软件的AIAgent小Day畅聊你的想法，或上传素材，并让它帮你创作、生成、管理壁纸。按【<u>`Ctrl+Enter`</u>】。

### Live动图（自定义壁纸）

你可以在这里导入高清图片设为壁纸，也可以导入GIF动图作为高清动态壁纸。

### Daily每日（推荐每日壁纸）【👍作者主推功能】

你可以在这里开启推送每日壁纸，向小Day描述或上传壁纸偏好，设置推送壁纸的时间间隔，支持开机一换，启动一换，一日一换，亦或几小时一换，几分钟一换。同时小Day会基于你的心情喜好，结合今天的时间地点、日期星期、节气节日、风俗风气、历史文化、等等各项因素定时向你展示具有浓郁气氛的精美高清壁纸！

### Param参数（配置参数）

你可以在这里热修改软件的各项参数，让其更符合你的个人使用习惯。

### Setting设置（配置设置）

你可以在这里调配各种软件设置，包括但不仅限于更改AI生成模型和AI解释模型来合理调节AI质量以及优化模型的token消耗流向，甚至进入调试模型和接入个人插件。

### Renew更新（更新）

你可以在这里，一键点击，放手更新。

### 项目整体

采用高内聚低耦合的设计原则，可扩展性高。

采用单例设计模式，控制资源集中共享与统一管理，避免数据冗余。

遵循类对象懒加载的设计原则，避免大量数据资源同时初始化造成集中卡顿。

基于主干开发（TBD），软件只维护当前的最新版本，不纠结历史版本和旧版问题。

面向接口编程，【<u>函数调用规则基本存在于接口类的注释文档中</u>】，大多数【<u>功能性宽泛的通用代码都以继承接口类内的默认方法获得</u>】，功能性具体的特定代码都以继承接口进而重写方法实现。

本项目的定位向工程化、工业化、商业化发展，因考虑到【<u>本项目为纯Java项目</u>】，所以在【<u>当前项目文件结构中选择性地保留了`.idea`文件夹</u>】，以便【<u>贡献者或合作者能够开箱即用地配置项目环境以及继续开发软件程序</u>】。



## ⭐技术细节

### Chat聊天

技术点在于这里维护一个AIAgent小Day，主要分成三大模块。一，Information信息背景，为它提供了软件背景和现实数据，让它的回复和创造更符合生活实际。二，Memory记忆，为它编写了一套记忆体系，以便让它可以结合长上下文分析数据，给出更具有个性化的回答和创作。三，FunctionCalling（Skills）技能，这里主要维护了几套工具调用分别是文本生成文本、文本生成图片、图片生成文本的识别和调用。同时还需要兼顾API密钥的保护和对敏感隐私数据加解密逻辑的便携和通用性，以及对异步数据的同步还有数据的实时渲染反馈响应逻辑。

### Live动图

技术点在于对于对动态图片GIF的分片切片，以及对于切片细节的修正，参数的修复。同时对于切片数据在本地的保存、离散复用和短期维护、扩展。还有对于Native的利用，调用操作系统自带的动态链接库（Windows-64对应的是user.dll）来进行壁纸的更换和动态壁纸的实现及优化维护。

### Daily每日

技术点在于对推送壁纸线程的维护，AI软编程的实现，推送提示词的优化，用户图像喜好与现实真实背景信息的综合考虑与有机结合，系统级开机自启的实现，权限的灵活管理，程序路径及线程的维护细节。

### Param参数

技术点在于对数据的灵活的抽拉，存储，使用以及渲染，兼具对功能的动态调整，以及对于重置功能的实现和复用。

### Setting设置

技术点在于对类似vue的数据渲染UI的响应式编程的理解和实现，采用约定大于配置的思想架构，自动记忆参数的实现，默认参数和用户参数之间的协调平衡，调试模式与日志功能的适配，以及对插件补丁的接入和利用的实现架构。

### Renew更新

技术点在于对网络的监测，资源占用的解决和优化，自动更新的实现，数据同步的尝试，以及在网络加速环境下访问web资源时对于SSL及其相关安全证书问题的安全评估和信任操作。
